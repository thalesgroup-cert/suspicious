# In-App Help Tour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Help button in the sidebar footer that launches a react-joyride guided tour (global nav steps + per-page steps), auto-running once on a user's first visit.

**Architecture:** A `HelpTourProvider` wraps `AppLayout`, calls the `useJoyride` v3 hook with steps chosen by current route, renders the `{Tour}` overlay, auto-starts once via a localStorage flag, and exposes `start()` through React context. A `HelpButton` in the sidebar footer (rendered inside the provider) calls `start()`. Step targets are `data-tour="..."` attributes on nav + page elements.

**Tech Stack:** React 19.2, TypeScript, MUI v9, react-router v7, Vitest + Testing Library, `react-joyride@^3` (v3 = first React-19-compatible release).

## Global Constraints

- **Library version:** `react-joyride@^3` (v3.0.2+). v2.x is broken on React 19 — never install it.
- **v3 API:** `import { useJoyride } from "react-joyride"` → `const { controls, on, state, Tour } = useJoyride({ continuous: true, steps })`. Launch with `controls.start()`. Render `{Tour}` in JSX. Step `target` is a CSS selector.
- **Path alias:** `@/` → `suspicious-ui/src/`.
- **Test render helper:** `renderWithProviders(ui, { initialPath })` from `@/test/utils` (wraps MemoryRouter + theme + query client). Mock modules with `vi.mock`.
- **localStorage key:** `suspicious.tour.seen` (mirrors existing `suspicious.sidebar.pinned` pattern in `AppLayout.tsx`). Wrap all localStorage access in try/catch — it may be blocked.
- **Commit style:** Conventional Commits (`feat:`, `test:`). All commands run from `suspicious-ui/`.

```ts
import type { Step } from "react-joyride";

// Steps whose targets are always mounted (desktop sidebar). Shown first, every page.
export const GLOBAL_STEPS: Step[] = [
  {
    target: '[data-tour="nav-primary"]',
    title: "Navigation",
    content: "Jump between the main sections of Suspicious from here.",
    placement: "right",
    disableBeacon: true,
  },
  {
    target: '[data-tour="nav-workspace"]',
    title: "Your workspace",
    content: "Investigations, campaigns, and alerts live in this group.",
    placement: "right",
  },
  {
    target: '[data-tour="user-card"]',
    title: "Your account",
    content: "Open your profile and appearance settings here.",
    placement: "right",
  },
  {
    target: '[data-tour="help"]',
    title: "Replay this tour",
    content: "Click Help any time to run this walkthrough again.",
    placement: "right",
  },
];

// Keyed by route prefix; matched longest-prefix-first against location.pathname.
export const PAGE_STEPS: Record<string, Step[]> = {
  "/submit": [
    {
      target: '[data-tour="submit-form"]',
      title: "Submit something suspicious",
      content: "Drop an email, file, URL, IP, or hash here to start an analysis.",
      placement: "top",
    },
  ],
};

export function getStepsForPath(pathname: string): Step[] {
  const key = Object.keys(PAGE_STEPS)
    .filter((prefix) => pathname === prefix || pathname.startsWith(prefix + "/"))
    .sort((a, b) => b.length - a.length)[0];
  return key ? [...GLOBAL_STEPS, ...PAGE_STEPS[key]] : [...GLOBAL_STEPS];
}
```

Create `suspicious-ui/src/features/help/useHelpTour.ts`:

```ts
import { createContext, useContext } from "react";

export interface HelpTourValue {
  start: () => void;
}

export const HelpTourContext = createContext<HelpTourValue | null>(null);

export function useHelpTour(): HelpTourValue {
  const ctx = useContext(HelpTourContext);
  if (!ctx) throw new Error("useHelpTour must be used within a HelpTourProvider");
  return ctx;
}
```

- [ ] **Step 4: Write the provider**

Create `suspicious-ui/src/features/help/HelpTourProvider.tsx`:

```tsx
import * as React from "react";
import { useLocation } from "react-router-dom";
import { useJoyride } from "react-joyride";
import { getStepsForPath } from "./tourSteps";
import { HelpTourContext } from "./useHelpTour";

const SEEN_KEY = "suspicious.tour.seen";

export function HelpTourProvider({ children }: { children: React.ReactNode }) {
  const location = useLocation();
  const steps = React.useMemo(() => getStepsForPath(location.pathname), [location.pathname]);

  const { controls, Tour } = useJoyride({ continuous: true, steps });

  const start = React.useCallback(() => controls.start(), [controls]);

  // Auto-run once for first-time users. Runs on first mount only.
  const started = React.useRef(false);
  React.useEffect(() => {
    if (started.current) return;
    started.current = true;
    let seen = false;
    try { seen = localStorage.getItem(SEEN_KEY) === "1"; } catch { /* blocked */ }
    if (!seen) {
      try { localStorage.setItem(SEEN_KEY, "1"); } catch { /* blocked */ }
      controls.start();
    }
  }, [controls]);

  const value = React.useMemo(() => ({ start }), [start]);

  return (
    <HelpTourContext.Provider value={value}>
      {children}
      {Tour}
    </HelpTourContext.Provider>
  );
}
```

## Notes / deferred (from spec)

- **Per-page tours:** only `/submit` is authored as the exemplar. Add more by extending `PAGE_STEPS` and dropping `data-tour` anchors on those pages — no code changes needed.
- **Theme-matched styling:** ships with react-joyride defaults. MUI-derived `styles` is a follow-up.
- **Missing targets:** avoided by design — global steps target the always-mounted desktop sidebar; page steps only load on their own route. react-joyride v3 also reports unresolved targets via `failures` and continues.
- **Mobile:** tour is desktop-first (sidebar lives in a drawer on mobile). Best-effort only; not a v1 requirement.
